## Overview

![screenshot](https://media.discordapp.net/attachments/1464634656463786118/1565448751294713947/Captura_de_tela_de_2026-10-29_16-33-53.png?ex=6ae4f142&is=6ae39fc2&hm=4cf90bdea473de34b2861e15ecdbd4ac961a326cf97871b55c1768cd023e9e56&=&format=webp&quality=lossless)

A responsive feature section component designed for SaaS products, showcasing key features with visual cards, emojis, and images.

### What I learned

During this project, I practiced layout structuring using modern CSS techniques:
- **Flexbox Layout:** Created a responsive layout using `flex-wrap: wrap` to gracefully organize cards across screen sizes.
- **Custom Styling:** Applied specific styling to individual elements, including custom background colors for emoji badges.
- **Google Fonts Integration:** Imported and utilized Google Fonts (`Lato`, `Outfit`, `Poppins`, `Sora`).

```css
main {
  width: 100%;
  padding: 0 24px;
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  justify-content: center;
  gap: 50px;
}
```

### Useful resources

- [Google Fonts](https://fonts.google.com/) - Provided the typography used in this challenge.

- Semantic HTML5 markup

## Features

- **Responsive Design:** Cards wrap automatically depending on the screen size using CSS Flexbox.
- **Dark Theme:** Styled with a sleek dark background (`#121826`) and card backgrounds (`#212936`).
- **Feature Cards:** Highlights key features using emoji badges, descriptive text, and accompanying illustrations.
